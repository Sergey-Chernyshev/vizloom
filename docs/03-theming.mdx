# Theming

Every colour, radius, font, shadow and duration is a CSS custom property prefixed `--vl-`.
A theme is a block of overrides; canvases read the same variables at their element and redraw
when a theme attribute changes.

## Light, dark, auto

```html
<html data-vl-theme="dark">
  <!-- whole page dark -->
  <section data-vl-theme="light">
    <!-- a light island inside -->
    <body data-vl-theme="auto">
      <!-- follow the OS -->
    </body>
  </section>
</html>
```

## Brand palette

```css
:root {
  --vl-accent: #0e7c66;
  --vl-cat-1: #0e7c66;
  --vl-cat-2: #e0912f;
  --vl-cat-3: #3c6fd8;
  --vl-font-family: 'Manrope', system-ui, sans-serif;
  --vl-radius-l: 8px;
}
[data-vl-theme='dark'] {
  --vl-accent: #34c3a3;
  --vl-cat-1: #34c3a3;
}
```

## Built-in alternative palettes

`data-vl-palette` on the theme root (or any ancestor) swaps series colours 1–6 and follows the
light/dark theme:

| Value   | Colours                                                                 |
| ------- | ----------------------------------------------------------------------- |
| `plus`  | the base set with a brighter blue and a lime in slots 5 and 6           |
| `okabe` | Okabe–Ito: the safest set for the most common kinds of colour blindness |

```html
<div data-vl-theme="dark" data-vl-palette="okabe">…</div>
```

## Tooltip tokens

Every chart's tooltip reads optional tokens, so one block restyles them all (unset tokens keep
the defaults): `--vl-tooltip-bg`, `-text`, `-label`, `-muted`, `-divider`, `-shadow`, `-radius`,
`-padding`, `-font-size`, `-line-height`, `-min-width`, `-title-gap`, `-title-line-height`,
`-row-gap`, `-row-height`, `-value-weight`, `-gap` (distance from the anchor, px) and
`--vl-tooltip-beak: block` for a beak on bubbles above or below the anchor.

```css
:root {
  --vl-tooltip-bg: #1f2430;
  --vl-tooltip-text: #fafaf7;
  --vl-tooltip-label: color-mix(in oklab, #fafaf7 70%, transparent);
  --vl-tooltip-shadow: none;
  --vl-tooltip-beak: block;
}
```

## Token groups

| Group    | Variables                                                                                            |
| -------- | ---------------------------------------------------------------------------------------------------- |
| Surfaces | `--vl-bg`, `--vl-surface`, `--vl-surface-raised`, `--vl-surface-sunken`, `--vl-surface-hover`        |
| Text     | `--vl-text`, `--vl-text-secondary`, `--vl-text-muted`                                                |
| Lines    | `--vl-border`, `--vl-border-strong`, `--vl-grid`, `--vl-axis`, `--vl-crosshair`                      |
| Tones    | `--vl-accent`, `--vl-positive`, `--vl-negative`, `--vl-warning` and their `-soft` backgrounds        |
| Series   | `--vl-cat-1` … `--vl-cat-8`, `--vl-cat-other`, `--vl-compare-1` … `--vl-compare-4`                   |
| Ramps    | `--vl-seq-from`, `--vl-seq-to`, `--vl-div-neg`, `--vl-div-mid`, `--vl-div-pos`                       |
| Shape    | `--vl-radius-s/m/l/pill`, `--vl-space-1…6`, `--vl-shadow-card`, `--vl-shadow-pop`, `--vl-focus-ring` |
| Type     | `--vl-font-family`, `--vl-font-mono`, `--vl-font-size-xs…kpi`, weights                               |
| Motion   | `--vl-duration-fast/base/slow`, `--vl-ease`, `--vl-ease-out`                                         |

## Series colours in code

```ts
import { seriesColor, compareColor } from 'vizloom/core';
seriesColor(0); // 'var(--vl-cat-1)'
compareColor(0); // 'var(--vl-compare-1)'
```

A series can also take any CSS colour: `{ id: 'vip', label: 'VIP', color: 'var(--brand)' }`.

## Contrast

`contrastRatio`, `readableOn`, `mixColors`, `sequentialRamp` and `divergingRamp` help build
accessible palettes; the built-in categorical palette is checked for colour-blind readers on
both themes (see **Core / Palette and tokens**).
